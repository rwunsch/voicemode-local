# Implement the approved Voice Orb

The current Voice Pill keeps its controls visible and represents the active speaker with a small dot. This plan implements Stephan's approved animated orb in the real Pill, with controls revealed when needed and motion driven by actual audio. It preserves the existing runtime commands so the new appearance does not change who owns the microphone or how a conversation pauses and stops.

Design: [2026-11-27-voice-orb.md](../specs/2026-11-27-voice-orb.md).

## Build-rules check

This work is in the upstream VoiceMode repository. Its own documented rules apply:

- `docs/superpowers/specs/2026-11-04-voice-pill-design.md`: real state, cheap polling, no heavy installation, no additional microphone and the same behaviour on Mac and Windows. Keep these constraints in renderer, levels and window tests.
- `docs/patching/README.md`: idempotent patches, loud failure on anchor drift and verification against pristine 8.12.0. Apply this to every new audio measurement hook.
- `docs/releasing/README.md`: full pristine-source suite and Node suite; report changed defaults and native checks. Do not perform merge/tag/release as part of the implementation PR.
