# Implement the approved Voice Orb

The current Voice Pill keeps its controls visible and represents the active speaker with a small dot. This plan implements Stephan's approved animated orb in the real Pill, with controls revealed when needed and motion driven by actual audio. It preserves the existing runtime commands so the new appearance does not change who owns the microphone or how a conversation pauses and stops.

Design: [2026-11-27-voice-orb.md](../specs/2026-11-27-voice-orb.md).

## Results and decisions during implementation

- Replaced the planned WebGL port with original CSS gradients and separate pigment/star layers. The effect needs no graphics package or third-party reference image.
- Levels are measured from samples the existing recording and playback paths already handle. The fixed-duration recording fallback can report Listening without a measured ring. No synthetic signal is substituted.
- A click names the current playback. The audio service ignores a command for an older playback or a recording already in progress. This is separate from Stop and from the voice-barge trigger.
- Chrome exercise passed with supplied state and level values, covering both colours, level expiry, hover and focus, interrupt routing, mini orb, menu-bar/rail transitions, reduced motion and classic appearance. Native macOS WebKit rendered the component, took and returned explicit key focus and forwarded the scoped interrupt to an isolated test backend.
- No installed FELIX settings, version, or files changed. A real audio session and native Windows remain to be tested before release.
